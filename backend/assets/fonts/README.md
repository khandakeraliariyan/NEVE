# Bundled fonts

Fonts for PDF reports, registered at startup by `src/config/fonts.js`, so Latin and Bangla text render on any host, including serverless hosts with no system fonts.

| File | Family | Source |
|---|---|---|
| `NotoSans-Regular.ttf`, `NotoSans-Bold.ttf` | Noto Sans | <https://github.com/notofonts/latin-greek-cyrillic> |
| `NotoSansBengali-Regular.ttf`, `NotoSansBengali-Bold.ttf` | Noto Sans Bengali | <https://github.com/notofonts/bengali> |
